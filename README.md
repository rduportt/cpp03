# CPP Module 03

> Inheritance.

## What's inside

- Class inheritance and construction / destruction order
- ClapTrap, ScavTrap, FragTrap
- DiamondTrap and the diamond problem

## Usage

```bash
cd ex00      # pick an exercise (ex00, ex01, ...)
make
./<executable>
```
Each exercise has its own Makefile and is compiled with `c++ -Wall -Wextra -Werror -std=c++98`.
